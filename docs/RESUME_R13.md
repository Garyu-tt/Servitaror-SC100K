# R13: synchronized rail quotient and resumable Linux

The compiler verifies that all five replicas of each rail have identical incoming synapses, that every source rail has uniform weights and that the graph is feedforward. It collapses only these synchronized replicas, evaluates exact integer synaptic current >=33 (equivalent to the original clipped current//3 >=11), and preserves spike counts. No Boolean ISA shortcut, memoized result or conventional guest arithmetic. Applied to ALU, decoder and control only; register and CSR state remain full rails. 440 differential checks and three ablations passed.

Run `python neural_resume_r13.py --checkpoint /tmp/sc100k-fixture.npz` for equivalence and exact checkpoint replay on the synthetic fixture. To execute real Linux use the pinned R12 image and `python neural_resume_r13.py --image Image --checkpoint linux.npz --budget 512`, then repeat with `--resume --budget 2048`. Checkpoint binds image SHA-256 and schema and stores RAM, recurrent rails, CSRs, peripheral state, reservation and counters at instruction boundaries. No arbitrary Python object loading. Only restore trusted locally produced checkpoints; this is not an authenticated checkpoint format.

Real measured result: 512 instructions in 2.766 s versus 11.645 s in R12 (4.21x for this probe, not general performance). Subsequent process restored checkpoint and retired 2048 more instructions, total 2560, 6002 ALU calls, no guest traps, still in early memory clearing. No UART output, Linux boot or DOOM yet. Checkpoint 4121853 bytes, stored on host /tmp; not durable across reboot. No checkpoint binary committed. Original disk remains full. Fixed separate circuits, not one continuous plastic GENESIS graph.
