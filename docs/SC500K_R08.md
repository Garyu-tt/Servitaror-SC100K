# SC500K R08: native graph telemetry and cold entry

Addresses the extended #9 requirements for continuous cold boot and real spatial connectome visualization. Adds read-only export of actual evaluated native representative spike states for the three explicit fixed feedforward circuits: ALU 28650 neurons/279000 edges, decoder 10040/97200, control 2460/14000. Stable identity is region + local graph index, five identical replicas per rail. Graph NPZ contains actual weighted edge lists and levels, not spatial coordinates. Per evaluation records packed rail bits, count, ordinal and instruction boundary; per boundary records PC, retirement, UART delta and framebuffer hash. Boundary is a guest step, not a continuous GENESIS tick. No claim to actual individual synaptic event capture, other regions, GENESIS spatial coordinates or complete live GUI. No invented brain shape. Bounded trace only, not a continuous demo. Raw trace and topology files retained locally with hashes in reports.

Local PASS: 120 ALU comparisons, ablation shows no internal spikes and rejects readout, paused recorder emits no events. 32 actual Linux instructions from checkpoint: 241 circuit evaluations, 2735525 expanded activations; full machine snapshot matches uninstrumented reference in independent 32-instruction replay, 0.0243 s reference vs 0.0399 s traced (excluding scanout). Cold mode starts at zero retired/boundaries, fresh memory and no restored state; actual Linux first 32 instructions, 151 evaluations, 1446275 expanded activations; initial record before first instruction. Host firmware loads kernel before tracing; firmware initialization is not traced. This is a cold-entry proof, not successful Linux boot. Actual continuing non-traced execution advances from 828425 to 848425 retired, 95015 new oracle checks, no new trap. Disassembly at 0xc02530e0–0xc02531d0 shows unrolled stores and loop consistent with memset; address advances, no evidence of a fixed-PC hang. UART unchanged. Final checkpoint SHA-256 a10278aeed4c721ae74f48de47da3b86921bdf8d0bddde2ab7b6de89f856a756. Reproduce: `python neural_trace_r34.py --build-dir /tmp/sc500k-trace` or add `--image /path/to/Image --cold --graph graph.npz --trace trace.json --steps 32`.
