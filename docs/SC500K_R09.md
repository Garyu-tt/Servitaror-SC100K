# SC500K R09: streaming demo launcher

Addresses #9. Local-only HTTP demo with guest UART, RGB scanout, actual native spike telemetry, run/pause/step controls, guest MMIO keyboard input. Server binds 127.0.0.1 and only advances on requests. Stream logs initial state before first guest instruction, per-boundary event counts, optional sampled rail bitsets, UART deltas and frame hashes at batch boundaries. Trace sampling and size limit are explicit (default every boundary, 256 MiB soft limit checked before each step). The display shows last measured evaluation for each region, not spontaneous activity. Cold mode initializes a fresh board, resume mode restores a checkpoint. Firmware initialization still precedes tracing. Keyboard is MMIO FIFO only, not a Linux shell input driver. Actual GENESIS XYZ absent: UI shows a rail-ID raster, not an anatomical model. Optional coordinate NPZ must supply exact region IDs and weighted edges, finite XYZ arrays; this checks identity, not independent coordinate provenance. Top XY, side YZ, front XZ; deterministic sampled points and structural edges. Actual coordinates and projection rendering not yet validated. No claim to synaptic event capture or full-network trace.

Local PASS: five-instruction fixture, UART X, key FIFO, no events during pause. Real Linux cold 64 instructions in bounded stream, 2720650 expanded activations. Loopback HTTP integration: fresh state at 0, step 1, run 64, pause unchanged, key accepted, missing coordinates rejected, 192000 RGB bytes, 65 boundaries/17 sampled, 2755550 measured activations. Browser visual rendering not tested; server stopped after test. No public endpoint. Reproduce: `python neural_demo_r35.py --build-dir /tmp/sc500k-demo --test`. Demo: `python neural_demo_r35.py --build-dir /tmp/sc500k-demo --image /path/to/Image --cold --graph graph.npz --trace trace.jsonl --trace-every 64 --serve`, then open http://127.0.0.1:8765 on the same host. Trace path must be new; stop with Ctrl-C. Optional checkpoint saved on clean stop. Raw traces/topology retained locally, reports committed.

Main non-traced boot separately advances from 848425 to 888425 instructions, 40000 new instructions, 190101 arithmetic comparisons, 42576 synaptic RAM reads and 8240 writes, no new traps or mismatches. UART unchanged, no Linux userspace/DOOM. Final checkpoint SHA-256 a86ed75b40e15f062ee3d805f8df770ed1df18cb68dfa6cb4d5c1a00530e325a.
