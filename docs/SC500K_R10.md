Host provides UART control registers, queue pointers and external I/O. Not a complete 16550 implementation: interrupts/PLIC and actual Linux console input remain unverified. RX adds estimated 10890 logical cells; total estimated 448450. The demo launcher now sends UTF-8 bytes directly to UART RX, with 32-byte limit and trace records. Session-level input tested; browser rendering and HTTP serial endpoint not independently retested in R10.
